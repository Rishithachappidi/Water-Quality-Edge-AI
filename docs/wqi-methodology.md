# Water Quality Index (WQI)

The manuscript uses Water Quality Index (WQI) as the water-quality assessment
metric.

The revised paper distinguishes WQI from machine-learning classification and
clarifies that the study uses a WQI-based assessment rather than claiming to
establish a completely new universal water-quality standard.

For exact equations, parameter weights, reference values, and permissible
limits, consult the final manuscript. This repository does not invent missing
parameters.
