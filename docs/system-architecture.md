# System Architecture

The proposed system is described as an IoT and edge-AI water-quality monitoring
framework.

Core elements described in the manuscript include:

1. Water-quality sensing
2. pH measurement
3. Turbidity measurement
4. TDS measurement
5. Edge-side processing
6. WQI-based assessment
7. Machine-learning analysis
8. Explainability
9. Monitoring/output

The exact source implementation and complete hardware wiring files were not
provided, so this document intentionally does not invent component-level
implementation details.
